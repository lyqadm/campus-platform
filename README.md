本项目为大学《软件工程》课程设计大作业。系统针对高校校园内教材、数码产品、代步工具等闲置物品流转难以及校园失物招领信息分散的痛点，采用 **FastAPI + SQLite + Vue 3 + ECharts** 轻量化全栈架构，实现了集**「二手集市交易、商品互动留言、校园失物招领、个人资产与发布管理、管理员实时数据大屏与内容审核」**于一体的综合互助平台。

## ✨ 核心功能模块

### 1. 🛒 二手集市大厅（买家/学生端）
- **多维检索与分类筛选：** 支持按关键词模糊匹配商品名称与描述，覆盖*数码电子、图书教材、生活百货、代步工具、文体乐器、运动健身、美妆个护、服饰鞋包* 8 大校园高频分类。
- **交易闭环与防呆校验：** 内置完整的购买事务校验（拦截已售出/未上架商品、禁止购买自己发布的商品、账户余额不足提醒），下单成功后自动扣减买家余额、增加卖家余额、更新商品状态并生成历史交易订单。
- **商品互动留言板：** 每个商品支持独立弹窗查看与发表留言评论，实时统计留言数量；支持本人删除自己的留言或管理员全局管理。

### 2. 📢 校园失物招领专区
- 支持发布 **「寻物启事」** 与 **「失物招领」** 两类信息，包含物品特征、丢失/拾取地点、联系方式与发布人追踪。
- 严格的权限控制：普通学生仅可删除本人发布的信息，系统管理员拥有全局清理权限。

### 3. 👤 个人中心与资金管理
- **模拟钱包充值：** 支持自定义金额或快捷面额（50 / 100 / 200 / 500 元）实时充值到账。
- **闲置上架与管理：** 表单完整性实时校验，支持查看「我发布的商品」并删除未成交商品（已成交或存在交易记录的商品自动锁定，防止破坏历史账单一致性）。
- **全平台交易流水：** 透明展示订单编号、买卖双方、成交金额与交易日期。

### 4. 📊 管理员后台与实时数据大屏（Admin 专属）
- **ECharts 实时可视化大屏：** 每 5 秒自动轮询增量刷新，动态渲染 **「在售商品分类占比饼图」** 与 **「近 7 日平台成交金额趋势折线图」**，支持窗口尺寸自适应重绘。
- **商品审核与违规风控：** 管理员可对商品执行「通过上架」、「强制下架」及「彻底删除」操作（级联清理对应商品留言，并对已产生交易记录的商品自动加锁保护）。

## 🛠️ 技术栈与工程亮点

| 层级 | 采用技术 | 工程选型优势（专为 2C2G 轻量云服务器优化） |
| :--- | :--- | :--- |
| **前端视图层** | HTML5 + CSS3 响应式布局 + Vue 3 | 免 Node.js 编译打包，支持 PC / 平板 / 手机自适应访问 |
| **数据可视化** | Apache ECharts 5 | 实例复用与每 5 秒增量刷新，上下架商品实时联动扇形图 |
| **后端服务层** | Python FastAPI + Uvicorn + Pydantic | 原生异步高并发，严格的数据模型校验，内存占用不足 60MB |
| **数据持久层** | SQLite 3 (`campus.db`) | 零外部数据库进程开销，单文件持久化，内置平滑数据库迁移与幂等种子数据填充 |
| **容灾与部署** | 阿里云 ECS + Cloudflare Pages | 前端内置智能 Fetch 双模拦截器，支持后端 API 与浏览器 `localStorage` 自动降级切换 |
